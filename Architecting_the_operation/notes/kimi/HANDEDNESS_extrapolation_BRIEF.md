# Research brief: does the record support the framework's extrapolation to handedness?

## Rules (read first)
- Write exactly ONE file: `Architecting_the_operation/notes/kimi/HANDEDNESS_extrapolation_FINDINGS.md`.
- Do not edit any other file. Do not run git or make.
- Use the web. Prefer peer-reviewed studies, meta-analyses, government data. A claim is only
  SUPPORTED by a source you opened. Quote exact words, under 25 per quote.
- Report evidence AGAINST each prediction with the same care as evidence for it. A prediction
  the record does not support is a valid and useful finding. Do not search only for support.

## Context
The manuscript (`Paper/The_Original_Power.tex`) models systemic friction with the Drude equation
(lines ~932-950): resistance R = mL / (n q^2 tau A), where tau is the mean free time between
collisions. "The Elite engineers high resistance for the Out-group by minimizing tau"; the lost
energy is I^2R loss ("trauma, stress, cognitive load"). Line ~4294 uses Audre Lorde's "mythical
norm" as the default against which every deviation becomes an axis. The book's six identity axes
are race, gender, religion, sexuality, nationality, ability. Handedness is not among them.
The author (left-handed) proposes extrapolating the framework to handedness. Test it.

## Predictions to test (one block each)
H1. Collisions: left-handed people experience more friction with tools, equipment, and
    infrastructure designed for right-handers. Look for injury/accident studies (e.g. Coren 1989
    and later work, including failures to replicate), task-performance studies with
    right-handed tools, workplace/industrial safety findings.
H2. I^2R loss: the friction carries measurable costs (injury, time, error, cognitive load).
H3. Enforced partition: forced conversion of left-handed children (which countries, which
    decades, how documented; any measured effects).
H4. Extraction: does anyone collect from the partition? (a) price premium for left-handed
    products ("left-handed tax"); (b) earnings gaps by handedness (e.g. Goodman 2014 J. Econ.
    Perspectives; Ruebeck, Harrington & Moffitt 2007; others) and which direction they point;
    (c) whether a single right-handed design is a documented cost saving for manufacturers.
H5. Ability linkage: does disability scholarship (social model of disability, universal design)
    treat handedness-hostile design as disabling? Any accessibility standards that address it?
H6. Current example: reports about an Apple foldable/dual-screen iPhone ("iPhone Duo" or
    similar) expected in 2026 and whether its hardware or UI is described as right-hand biased.
    If no reliable report exists, say so.

## Output format
For each H: Verdict (SUPPORTED / MIXED / NOT SUPPORTED / UNVERIFIED), the 2-4 best sources with
quotes, effect sizes where reported, and one sentence on what the evidence licenses a podcast
host to say on air. End with a summary table and a one-paragraph classification: is handedness
best described in the framework's terms as (a) friction from a design default, (b) a
historically enforced partition, (c) an active extraction axis, or some combination, and how
strong is the evidence for each.
