# Fact-check brief — EP04 cold open sources

## Rules (read first)
- Write exactly ONE file: `Architecting_the_operation/notes/kimi/EP04_factcheck_FINDINGS.md`.
- Do not edit any other file. Do not run git. Do not run make.
- Use the web. Prefer primary sources (FBI/BJS tables, court records, university and DA
  statements, the Cornell Daily Sun, PBS/NPR/AP). A claim is only CONFIRMED by a source you
  actually opened. Quote the exact supporting words, under 25 words per quote.
- This is a public podcast about a live sexual-assault case. Accuracy beats completeness.
  Returning UNVERIFIED is a correct answer. A loose match is worse than an honest blank.
- Use swarm/parallel workers: one worker per claim is the natural split.

## Output format (one block per claim, in this order)
```
### C<n> — <short label>
Claim: <the claim as stated>
Verdict: CONFIRMED | PARTLY TRUE | CONTRADICTED | UNVERIFIED
Correct figure / fact: <what the record actually says, with year and table name>
Source: <URL> — "<exact quote>"
Note: <anything that changes how the claim can be said on air>
```
End with a short table: claim id → verdict.
