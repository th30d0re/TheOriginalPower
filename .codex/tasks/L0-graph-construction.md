## Objective

Materialize the framework knowledge graph as a queryable artifact. It does not
exist yet; every other loop depends on it.

**Nodes** — registry equations (E001–E239), symbols from `variables.yaml`, anchor
cases, the five tier sets (E, P_uppet, F_enforce, I_buffer, O_racialized),
contract entries from `contract_catalog.yaml`.

**Edges** — `derives_from` (equation → equation), `calibrates` (case → equation),
`falsifies` (criterion → equation), `maps_to` (framework variable → market
contract).

## Inputs available

- `equation_explorer/data/equations.json` — 239 equations with `id`, `chapter`, `chapterIndex`, `section`, `label`, `latex`. This is the highest-quality structured input; start here.
- `Paper/empirical_index.tex` — generated index with per-equation tier, case-study location, primary source, falsification criterion. Generated by `Paper/scripts/generate_index.py`; read that script to understand the schema rather than parsing the LaTeX by hand.
- `systemic_arbitrage/variables.yaml`, `systemic_arbitrage/contract_catalog.yaml`.

## Output

- `systemic_arbitrage/graph_build.py` — deterministic builder, runnable as `python -m systemic_arbitrage.graph_build`.
- `systemic_arbitrage/data/graph/framework_kg.json` — typed triples. Every node carries `id`, `type`, `tier`, `provenance`. Every edge carries `source`, `relation`, `target`, `provenance`.
- `systemic_arbitrage/tests/test_graph_build.py` — pytest coverage.
- A `make arbitrage-graph` target in the root `Makefile`, following the style of the existing `arbitrage-*` targets.

## Hard constraints

1. **Deterministic extraction only.** Do not call an LLM to infer edges. Where a relationship cannot be derived from structured sources, emit nothing and record the gap in a `gaps` array in the output. Loops L1 and L4 handle generated edges under a separate validation path; that is explicitly not your job.
2. Every node and edge carries `provenance` naming the file it came from.
3. Never write outside your worktree.
4. Do not modify `Paper/` — it is manuscript source.

## Exit criteria (from GRAPH.md)

- Every equation in the registry appears as a node.
- Every anchor case links to at least one equation.
- Zero orphan nodes (or each orphan is explicitly listed in `gaps` with a reason).
- `pytest systemic_arbitrage/tests/test_graph_build.py` passes.
